# Heykal Security

Elite physical security & surveillance — corporate website built with Next.js 16, Tailwind CSS, and Framer Motion.

## Design

**Ivory & Onyx** luxury editorial theme with warm amber/copper accents from the Obsidian Ember palette.

- **Typography**: Playfair Display (serif), Outfit (display), Inter (body), Rajdhani (tactical)
- **Palette**: Ivory backgrounds, gold/amber/copper accents, dark navy text
- **Motion**: Cinematic parallax hero, scroll-driven animations, reduced-motion safe

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view.

## Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Fonts**: Google Fonts via `next/font`

## Deploy

Deploy on [Vercel](https://vercel.com) — no additional configuration needed.
